# LifeOS Organizer Safety Rules

1. Inventory first.
2. Read-only before remediation.
3. Proposal before movement.
4. Explicit human approval before any mutation.
5. No deletion during the initial project.
6. Every future mutation must be logged.
7. Every future move must have a rollback map.
8. Downloads and Desktop will not be cleaned automatically.
9. External disks and cloud folders require separate approval.
